مستندات راه‌اندازی (Termux + Cloudflare Tunnel)
HTTPS الزامی است — HTTP و file:// کار نمی‌کند
1) الزام HTTPS
Telegram Web Apps فقط روی HTTPS لود می‌شوند. بنابراین از http:// یا file:// استفاده نکنید.
2) معماری پیشنهادی
  • Frontend: همین index.html (WebApp)
  • Backend: FastAPI روی Termux (Verify initData با Bot Token)
  • Expose: Cloudflare Tunnel (cloudflared) برای HTTPS
3) نمونه فرمت درخواست‌ها (FastAPI)
این کد نمونه کامل نیست؛ فقط فرمت مورد انتظار Frontend را نشان می‌دهد.
# Backend sample (FastAPI) — runs in Termux
# IMPORTANT: verify initData using bot token (HMAC SHA256)

GET  /status
Headers:
  X-Tg-Init-Data: <Telegram.WebApp.initData>

GET  /users
Headers:
  X-Tg-Init-Data: <initData>

POST /settings
Body (JSON):
{
  "initData": "<initData>",
  "settings": {
    "messenger_enabled": true,
    "downloader_enabled": true,
    "uploader_enabled": true,
    "maintenance_mode": false,
    "welcome_message": "...",
    "default_daily_limit": 10,
    "default_size_limit_mb": 500
  }
}

POST /users/block
Body:
{ "initData": "<initData>", "user_id": 123 }

POST /users/unblock
Body:
{ "initData": "<initData>", "user_id": 123 }
4) دکمه WebApp در ربات (Python)
# Pyrogram example: send WebApp button
from pyrogram.types import InlineKeyboardMarkup, InlineKeyboardButton, WebAppInfo

WEBAPP_URL = "https://YOUR-HTTPS-DOMAIN/index.html"

keyboard = InlineKeyboardMarkup([
  [InlineKeyboardButton("🎛 Admin Panel", web_app=WebAppInfo(url=WEBAPP_URL))]
])

await bot.send_message(ADMIN_ID, "Open admin panel:", reply_markup=keyboard)
نکته: URL باید HTTPS باشد و در BotFather هم دامنه WebApp مجاز شده باشد.
5) راه‌اندازی در Termux + Cloudflare Tunnel (مرحله‌به‌مرحله)
# Termux steps
pkg update -y && pkg upgrade -y
pkg install python git -y
pip install fastapi uvicorn

# Run backend (example)
uvicorn app:app --host 127.0.0.1 --port 8000

# Host frontend (simple) — better: serve via backend static
python -m http.server 8080 --bind 127.0.0.1

# Install cloudflared
pkg install cloudflared -y

# Expose frontend (HTTPS URL)
cloudflared tunnel --url http://127.0.0.1:8080

# Expose backend (another tunnel) OR serve WebApp + API from same FastAPI
cloudflared tunnel --url http://127.0.0.1:8000

# Use generated https://....trycloudflare.com URL in WEBAPP_URL
پیشنهاد حرفه‌ای: WebApp و API را روی یک FastAPI سرو کنید تا فقط یک دامنه لازم باشد.
